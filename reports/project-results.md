## Performance Indicators

| Metric | Purpose |
|---|---|
| Fault identification rate | Measures how accurately FibreTrace identifies network faults. |
| False positive rate | Measures how often FibreTrace reports a fault when the network is healthy. |
| Detection time | Measures how long FibreTrace takes to identify a fault. |
| Restoration time | Measures how long it takes to restore normal network operation. |
| Packet loss | Measures the percentage of packets that fail to reach their destination. |
| Latency | Measures network response time in milliseconds. |
| Jitter | Measures variation in network response time. |
| Service availability | Measures whether network services are responding. |
| Test coverage | Measures how many planned tests have been completed. |
